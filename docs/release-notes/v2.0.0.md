# MouseFence 2.0.0

MouseFence 2.0 is a standalone Rust application for Windows 10 and 11 x64. Download
`MouseFence-win-x64.exe`; no .NET runtime or installer is needed.

The familiar tray controls, English and Turkish settings, directional monitor fences, firm-push
crossing, pause and game mode remain. The decision engine and settings are checked against the pinned
1.1.1 reference implementation. Tray notifications stay quiet during ordinary operation.

## Upgrade from 1.x

1. Exit the running MouseFence instance from its tray menu.
2. Replace its executable with the 2.0 executable and start it once.
3. On the first launch, 2.0 imports the 1.x settings read-only into
   `%APPDATA%\MouseFence\v2\settings.json`. The original 1.x settings stay available for rollback.

The executable remains unsigned, so Windows SmartScreen may ask you to confirm the download.
Compare its SHA256 with `MouseFence-win-x64.exe.sha256`. Verify the GitHub build attestation with:

```powershell
gh attestation verify MouseFence-win-x64.exe -R (gh repo view --json nameWithOwner --jq .nameWithOwner)
```

The 1.x release line is unsupported after **2026-11-10**. Its pinned source remains available as the
parity reference for development; it is excluded from the shipped executable. PDB symbols are built for
diagnostics and are excluded from the release downloads.
