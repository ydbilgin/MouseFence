# MouseFence 2.0.2

A small reliability update to 2.0.1. Settings, shortcuts and behaviour stay the same.

## What changed for you

- Protection comes back if another program stops it. Any program in your Windows session could post a quit
  message to MouseFence's mouse-hook thread; the fences then stayed off until you restarted MouseFence. Now
  the regular health check notices and starts a new hook thread with the same settings and switches, and
  `error.log` says why.
- A start that cannot run says why. MouseFence runs once per Windows session. If an older MouseFence 1.x or
  another program holds its single-instance name and no MouseFence 2 tray icon is running, it no longer exits
  without a word: it writes the reason to `%APPDATA%\MouseFence\v2\error.log` (exit code 7). Close the other
  copy, or sign out and in again.
- The program and tray icons use the current MouseFence artwork.

## Upgrade

Exit MouseFence from its tray menu, replace `MouseFence-win-x64.exe` with the new file and start it.
Your settings in `%APPDATA%\MouseFence\v2\` are kept. Upgrading from 1.x works as described in the 2.0.1 notes.
