# MouseFence 2.0.1

I rebuilt MouseFence in Rust. It still does the same job: it keeps the mouse pointer on the screen you meant
to use. It is now one standalone program for Windows 10 and 11 (64-bit). It needs no .NET runtime and no
installer.

## What changed for you

- A new icon, in the tray and in the app.
- Deliberate crossings. MouseFence now looks at how the pointer arrives at a closed edge. A firm push that
  keeps going crosses after a short hold. Slow drifting, grazing along the edge and short flicks (a game
  swipe, for example) still stop at the edge. The ease slider in Settings tunes all of this together.
- Protection recovers by itself. Windows can silently drop a mouse hook. MouseFence notices, recreates the
  hook on the current input desktop and tries again a limited number of times per outage. If it cannot
  confirm protection, the tray says so instead of staying quiet.
- Settings from 1.x are imported on first start. The old settings file is only read, never changed, so you can
  go back.

## Upgrade from 1.x

1. Exit the running MouseFence from its tray menu.
2. Replace the old executable with `MouseFence-win-x64.exe` and start it once.
3. On first start it copies your 1.x settings into `%APPDATA%\MouseFence\v2\settings.json`.

The 1.x line gets no more fixes after **2026-11-10**.

## How this file was built

I built it from this repository at the commit that contains these notes, on Linux with Rust 1.98.1,
cross-compiled for `x86_64-pc-windows-msvc` with `cargo xwin` (locked dependencies, static C runtime,
source paths removed from the binary). It is not a GitHub Actions build and has no build attestation.
Two builds of the same source give the same program; they differ only in a few bytes of debug
identity (the PDB id and a timestamp) in the file header. The PDB is not included in the download.
